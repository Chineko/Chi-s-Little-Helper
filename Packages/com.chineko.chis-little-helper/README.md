# Chi's Little Helper

Chi's Little Helper is a modular Unity Editor toolkit for VRChat avatar creators.

Open it from:

`Tools > Chi's Little Helper`

## Highlights

- Pre-Upload Check and Avatar Doctor 2.0
- Animator & Parameters Doctor
- Animation Swapper & Usage Map
- PC / Quest Comparator
- Texture & VRAM Analyzer
- Material Inspector++ and Material Assembler
- PhysBone Manager, Contact Setup, and Constraint Toolkit
- VRCFury workflow helpers and Overview++
- Preset Library, Snapshot & Compare, reporting, support bundles, and installation-health checks

## Requirements

- Unity 2022.3
- VRChat SDK - Avatars (VPM package `com.vrchat.avatars`)
- VRCFury is optional; VRCFury-specific features are detected through reflection and can be hidden in Preferences.

## Installation

Add the Chi's Little Helper VPM repository to VCC:

`https://raw.githubusercontent.com/Chineko/Chi-s-Little-Helper/main/Website/index.json`

Or use the one-click link:

[VCC: Add Chi's Little Helper Repository](vcc://vpm/addRepo?url=https://raw.githubusercontent.com/Chineko/Chi-s-Little-Helper/main/Website/index.json)

Then open your avatar project in VCC and install **Chi's Little Helper** from **Manage Project → Packages**.

Do not keep an older manual `Assets/Editor` copy installed beside the VPM package. Remove the old copy before switching to the VCC-managed package.
